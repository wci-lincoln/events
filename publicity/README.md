# Shiloh 2026 publicity kit · WCI Lincoln

Ready-to-post graphics, animations and videos for WhatsApp, Instagram, Facebook, TikTok and the
church projector, all pointing people to the Shiloh 2026 page by QR code:
https://wci-lincoln.github.io/events/shiloh-2026/

Everything is in `out/`. Sizes: **story** = 1080×1920 (WhatsApp status, Instagram and Facebook
stories, TikTok photo mode), **square** = 1080×1080 (Instagram and Facebook feed), **cover** =
1640×924 (Facebook page cover), **wide** = 16:9 for the projector. GIFs play inline on WhatsApp
and Instagram; WhatsApp turns them into short videos when you send them. MP4s are H.264, silent,
and work everywhere: WhatsApp, Reels, TikTok, Facebook, PowerPoint, Keynote, VLC.

The logo is the church's own emblem from winnerschapellincoln.org.uk, with a white version for
dark backgrounds. Both are in the kit as `00-logo-colour.png` and `00-logo-white.png`.

## Projector film

`30-projector-announcement.mp4` is a 54-second silent film for the screen in church while the
announcer speaks: the church lockup, the theme with Papa, dates and venue, a day at Shiloh, the
free bus, the seven classes, what else is on the page, and a big QR code to finish. It is built
to loop, so set it to repeat in PowerPoint, Keynote or the media player and let it run under
the announcements every Sunday and Wednesday from now until Shiloh.

## Making changes

The designs are HTML files in `src/`, sharing `shared.css` and `shared.js`. Edit the words there,
then run:

```
npm install
node build.js               # everything
node build.js 05-bus        # just the files whose name contains this
node build.js countdown     # the service-day countdowns
node build.js story         # just the story-size files
node build.js projector     # the projector film
node verify-qr.js           # decode the QR in every card and check it opens the Shiloh page
```

`build.js` renders with the Chrome installed on this Mac. GIFs are built in Node; MP4s use the
ffmpeg that `npm install` brings in with the `ffmpeg-static` package, so nothing else needs
installing. The countdown dates live in the `SERVICES` list in `build.js`: change a date, the days
left or the design number there and rebuild. Projector scene timings are the `data-a` attributes in
`src/projector.html` ("animation duration start").

`node frames.js countdown` and `node frames.js projector` capture still frames of the animations
into `preview/` for checking a design before a full render.
